# 原型资产(wayfinder 票 T07 / T09)

**这些是决策用粗样,不是产品代码;执行阶段在 `src/` 全新实现,本目录永不合并进产品。**

## T07 · 命盘 3D 构图三变体(浏览器直接打开)

| 文件 | 构图 | 一句话 |
|---|---|---|
| `t07/variant-a-ring.html` | 环形十二宫 | 平置浑仪刻度环,鎏金星球沿弧排布,朱砂八面体标四化,整体缓速自转 |
| `t07/variant-b-grid.html` | 传统方阵立体化 | 4×4 青铜地盘,宫格浮凸,星钉立于格上,中心 2×2 盘芯刻文 |
| `t07/variant-c-armillary.html` | 双环浑仪 | 外环十二宫板块 + 内环地支刻度反向自转 + 交叉骨架环,雕塑感最强 |

三变体共用:暖炭底 / 青铜锈绿 / 鎏金星曜 / 朱砂四化;盘面数据为**手造样例**(非引擎输出);点击宫位出右侧解读面板(联动形态示意)。three.js 0.187.0 已本地化于 `lib/`(importmap 引用,双击即可运行,无需服务器)。

## 复核清单(impeccable · T01)

- [ ] 色彩即语义:鎏金=星曜/主强调,朱砂=四化,无第三处高亮滥用
- [ ] 3D 元素对齐真实数据:宫位顺序、星曜大小分级、四化标记可对应引擎输出
- [ ] 无虚假氛围:原型里没有为炫而炫的光效,自转速率克制
- [ ] 首屏即工具的延伸:构图服务"找到我的宫位",不是布景
